# Active data

This folder is the sole input location for the current pipeline.

- `raw/`: original source statistics, unchanged apart from relocation.
- `external/`: external player metadata and source-linked, auditable supplements.
- `processed/`: regenerated model-ready tables with stable player IDs and
  complete covariates.

See [`../../README.md`](../../README.md) for counts, covariates, and provenance.
